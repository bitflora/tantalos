# Favorites

Generated levels that were especially good to play. Each `.p2c` opens in the Portal 2 Puzzle Maker
(`python train/playtest.py favorites/X.p2c` copies it into `portal2/puzzles/<steamid64>/` with
today's date); `favorites.jsonl` has one line per level with its
tokens, the run that sampled it, the solver's metrics and why it was saved.
